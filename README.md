# АРМ ДСП · Сокологірне — навчальний симулятор

Статичний браузерний симулятор робочого місця чергового по станції (за принципами АРМ-Ц ДСП МПЦ-У).
**Навчальна модель.** Не підключена до реальної залізничної інфраструктури. Час подій у графіку вигаданий.

## Файли
| Файл | Призначення |
|---|---|
| `index.html` | сторінка (розмітка, підключення скриптів) |
| `css/style.css` | оформлення |
| `js/topology.js` | **топологія**: вузли, секції, стрілки (+/−), світлофори, маршрути (шлях вузлами) — правиться без зміни коду |
| `js/schedule.js` | **модельний графік** (JSON із завдання дослівно) + `MODEL_PARAMS` (швидкості, витримки, переваги колій) |
| `js/generator.js` | **генератор добового графіка** за номером варіанта: електропоїзди із зупинкою, пасажирські, Інтерсіті, вантажні з обгонами; рідкий / середній / інтенсивний рух |
| `js/history.js` | історичні відомості з рівнем підтвердження |
| `js/engine.js` | логіка: замикання, ворожі маршрути, рух поїздів, журнал (без DOM, детермінована, крок 1 с) |
| `js/ui.js` | схема (плавний / пультовий вид), панелі, команди, діалог коду пильності |

## Запуск локально
Відкрийте `index.html` у браузері (сервер не потрібен) або `python3 -m http.server` і `http://localhost:8000`.

## Публікація на GitHub Pages (безкоштовно)
1. Створіть репозиторій на GitHub, завантажте вміст цієї теки в корінь (`index.html` має бути в корені).
2. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, тека `/ (root)` → Save.
3. Через 1–2 хв сайт буде на `https://<користувач>.github.io/<репозиторій>/`.

## Як користуватися
Натисніть **?** у верхньому рядку — там коротка інструкція з прийому і відправлення.

- Клацніть **світлофор** → список маршрутів від нього: МН (задати), ВС/ЗС (відкрити/закрити), МВ (відміна, відповідальна — код пильності).
- Клацніть **стрілку** → переведення, індивідуальне замикання, блокування. **Секцію** → блокування, ШР (штучне розмикання).
- За замовчуванням керування ручне: поїзд стоїть біля червоного, доки ДСП не задасть маршрут; запізнення показується червоним. «Автодиспетчер» задає маршрути сам.
- «Задати маршрут» одразу замикає маршрут і відкриває світлофор: зелений у режимі ПОЇЗДН., білий у режимі МАНЕВР.
- Для кожного поїзда графік підказує колію прийому (модель: пасажирські — I/II, вантажні — 3/4).
- Затримку поїзда вводять у таблиці графіка (хв). Тестовий поїзд — у формі «Тестовий поїзд».

## Механіка за посібником (с. 136–165)
- Маршрут: світлофор → «Встановити поїзний/маневровий маршрут» → клік на кінцевий світлофор (лінія за курсором, кінці підсвічені). Прийом закінчується на зустрічному світлофорі на початку колії (Н→I — М11, Ч→II — М18 тощо) або на самій колії; відправлення — на ЧД (Партизани) або кнопці ВЯ (Якимівка).
- Стрілки переводяться ~4 с (номер блимає), ділянки обводяться кольором маршруту, замикаються (світло-сіра заливка), світлофор відкривається. У маневрових маршрутах попутні маневрові світлофори відкриваються самі.
- Відміна: три комплекти — ВІЛЬН. 6 с, МАНЕВР. 60 с, ПОЇЗД. 180 с; зайнятий комплект не приймає нову відміну.
- Штучне розмикання 3 хв (ІР), запрошувальний сигнал (≤20 км/год), допоміжне переведення стрілок при хибній зайнятості, блокування світлофорів/стрілок/ділянок, лічильники відповідальних команд.
- Навчальні несправності: хибна зайнятість ділянки, втрата контролю стрілки (РОЗРІЗ СТР.).
- Усі світлофори з плану керовані: 11 поїзних і 15 маневрових; маневрові маршрути генеруються автоматично від світлофора до світлофора. С30 на плані позначений іншим знаком — показаний як об'єкт без керування.
- Напрямок маневрових світлофорів визначено за розміщенням на плані (над колією — парний напрямок, під колією — непарний), це припущення.
- Перевірка накладань: жоден текст чи значок не лежить на колії, стрілці чи іншому тексті (автоматичний тест у браузері).

## Графік і маневри
- Таблиця графіка перебудовується щоразу, коли змінюється добовий графік (нова доба, новий варіант, скидання); тестові поїзди вносяться в неї.
- «Графік руху» (canvas): план пунктиром, виконаний рух суцільною лінією, маневри — смуги на станції, поточний час — червона вертикаль.
- Маневрові роботи (`MODEL_PARAMS.shuntingJobs`): ЕЧ-14, Т-15, ПЧ-10, 8-10, 4-6, 3-I; генератор ставить 5 / 8 / 12 на добу залежно від інтенсивності.

## Відображення
Схема квадратна: усі відгалуження під 45° (екранні координати — `displayNodes` у `topology.js`, топологія не змінюється). Пультовий стиль за посібником (табл. 2.14–2.21): чорний фон, секції — білий контур; замкнена — світло-сіра заливка (контур зелений — поїзний, жовтий — маневровий); зайнята — червона; маневровий закритий — синій, відкритий — білий; індикатори СКАСУВАННЯ (3 хв / 1 хв) та ІР.

## Модельні припущення (перевірити за документацією)
- Колії I, II, 3, 4, 6, 8 поділено на 3 блоки, наближення/віддалення — на 2; стрілочні секції — по одній на стрілку. Поїзд займає 2–5 блоків залежно від номера.
- Назви секцій (1СП, 9-17СП, 18-20СП…) утворено з номерів стрілок — умовні.
- Плюс/мінус стрілок визначено за геометрією креслення.
- Сигнал М9 (з'єднання 19→15) вважається виходом з колій 14/15 — це припущення, тому маневровий сценарій MN-* вимкнено за замовчуванням.
- Координати схеми — пікселі оригінального плану (2576×422).
- Маневрові сигнали М1–М22, С30, ЧД показано лише для орієнтації.
- Довжини колій 10, 14, 15 не вказані — умовні.
- Поїзд з'являється на ділянці наближення за 3 хв (пас.) / 5 хв (ван.) до модельного часу; швидкості 60/40/15 км/год.

## Перевірено
Пуск/пауза/швидкості/скидання; перехід через 23:59 (новий день або зупинка); зайняття та посекційне розмикання;
відмова у відкритті сигналу без маршруту; блокування ворожого маршруту; журнал; ширина 400 px без горизонтальної прокрутки;
два прогони доби з однаковими налаштуваннями дають ідентичний журнал; критичних помилок у консолі немає.

## Правила приймання в моделі (спрощено з практики ПТЕ/ТРА, не з ТРА станції)
- Інтерсіті та пасажирські без зупинки — головні колії I (непарні) / II (парні).
- Електропоїзди із зупинкою — колії біля платформ: I, II (острівна), 3 (бокова).
- Вантажний, за яким близько йде швидший поїзд, — на бічну 3/4/6 для обгону.
- Порушення пишуться в журнал як попередження.
